# Automate build testing and deployment of your PowerShell modules cross platform with Azure DevOps

**Speaker(s):** Mark Wragg — session on the [MiniCon26](https://synedgy.com/psconfeu-minicon/) agenda.

## Abstract

In this session I will describe how a free Azure DevOps account can be used to implement CI/CD for PowerShell modules. I will cover how a build pipeline can be used to run tests, execute PSScriptAnalyzer, combine the module into a single PSM1 for performance and deploy to the PowerShell Gallery, executed automatically against commits and PRs to always ensure you deploy good quality working code. I will also cover some how to improve the performance of your pipeline by using caching for dependencies, and running parallel jobs when testing across multiple Operating Systems, Windows PowerShell and PowerShell Core.
